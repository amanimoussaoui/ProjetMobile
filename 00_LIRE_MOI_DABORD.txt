                        PROCHAINES ÉTAPES
═══════════════════════════════════════════════════════════════════

⚠️ IMPORTANT - À FAIRE MAINTENANT:

1. 📥 Ajouter google-services.json
   Placer dans: app/google-services.json
   Source: Firebase Console

2. 🔄 Sync Gradle
   File → Sync Now (attendre 1-2 min)

3. 🏗️ Créer Émulateur
   Tools → Device Manager → Create Device
   Recommandé: Pixel 6, API 34

4. ▶️ Lancer l'App
   Cliquer le bouton Run
   Attendre 2-3 min pour build

5. ✅ Tester
   • Cliquer sur chaque onglet
   • Vérifier les transitions
   • Voir "Accueil", "Événements", etc.

⏱️ Temps estimé: 10-15 minutes
